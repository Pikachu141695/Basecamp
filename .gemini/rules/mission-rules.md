# Basecamp 미션 관리 및 README 작성 규칙

## 1. 베이스캠프(Basecamp) 저장소 역할
- Basecamp는 1년 동안 진행할 다양한 학습 미션들을 통합 관리하는 작업소(허브/대시보드)이다.
- **Basecamp 루트의 README.md**는 전체 미션들의 진행 현황(로드맵)과 각 미션의 **간단한 요약 및 링크**만 작성한다.

## 2. 각 미션 폴더의 역할
- 각 미션은 독립 디렉토리(예: `Mission1-2/`) 단위로 관리한다.
- **각 미션 폴더 내의 README.md**에 아래의 모든 상세 내용을 충실하게 작성한다:
  1. 프로젝트 개요
  2. 퀴즈/과제 주제 선정 이유
  3. 실행 방법
  4. 기능 목록
  5. 파일 구조
  6. 데이터 파일 설명(state.json 등)
  7. 각 브랜치별 설명 (main, feature/* 등) 및 브랜치 히스토리

## 3. Git 및 브랜치 규칙
- 신규 기능 추가 또는 미션 작업 시 반드시 별도 feature 브랜치를 생성(`checkout -b`)하여 작업하고, 검증 완료 후 `main`에 병합(`merge`)한다.
- 각 브랜치의 역할과 설명을 해당 미션의 README.md에 기록한다.
