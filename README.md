# 🎯 Basecamp - Mission 1-2: 파이썬 객관식 퀴즈 게임 (CLI)

> 터미널 환경에서 파이썬 기초 개념을 학습하고 테스트할 수 있는 대화형 4지선다 퀴즈 프로그램입니다.  
> 객체지향 설계(OOP)와 JSON 파일 기반 데이터 영속화(Persistence)를 적용하여 프로그램 재실행 시에도 추가한 퀴즈와 역대 최고 점수가 안전하게 유지됩니다.

## 1. 프로젝트 개요
- **프로젝트명**: Mission 1-2 파이썬 객관식 퀴즈 게임
- **개발 환경**: Python 3.8+ (표준 내장 라이브러리만 사용, 별도 패키지 설치 불필요)
- **주요 특징**:
  - `Quiz` 클래스와 `QuizGame` 클래스를 통한 객체지향적 책임 분리
  - 모든 문제를 4지선다형 객관식으로 통일하여 직관적인 UX 제공 (번호 1~4 또는 보기 내용 입력 지원)
  - 프로젝트 루트의 `state.json` 파일에 UTF-8 인코딩으로 데이터를 저장하여, 재시작 시에도 **추가/삭제된 퀴즈**와 **역대 최고 점수** 유지

---

## 2. 퀴즈 주제 선정 이유
- **선정 주제**: **"파이썬 기초 문법 및 핵심 개념"** (내장 함수, 컬렉션 자료형, 불변 객체, 제어문 등)
- **선정 이유**:
  1. **필수 기초 개념 복습**: 파이썬 프로그래밍을 시작할 때 반드시 숙지해야 하는 표준 입출력(`print`), 길이 측정(`len`), 불변 시퀀스 자료형(`tuple`), 루프 탈출(`break`), 불리언(`bool`) 등의 핵심 개념을 확실히 다지기 위해 선정했습니다.
  2. **학습 진입 장벽 완화**: 단답식/서술식 입력의 오타나 공백 오류를 방지하기 위해 4지선다 객관식 형식을 채택하여 누구나 쉽고 재미있게 참여할 수 있도록 설계했습니다.
  3. **나만의 문제 은행 확장**: 기본 제공 문제(5문항) 외에도 사용자가 직접 학습하고 싶은 문제를 추가하거나 관리할 수 있어 개인 맞춤형 퀴즈 도구로 유연하게 활용할 수 있습니다.

## 3. 실행 방법

### 요구 사항
- Python 3.8 이상 설치 환경
- 파이썬 표준 라이브러리(`json`, `os`, `random`)를 사용하므로 추가 `pip install` 과정이 필요하지 않습니다.

### 실행 명령어
터미널에서 아래 명령어를 입력하여 프로그램을 실행합니다:

```bash
# 프로젝트 루트에서 바로 실행
python main.py
```

또는 `Mission1-2` 디렉토리로 이동하여 실행:
```bash
cd Mission1-2
python main.py
```

## 4. 기능 목록

| 번호 | 메뉴 | 주요 기능 설명 |
|:---:|:---|:---|
| **1** | **퀴즈 풀기 (기본 순서)** | 등록된 문제 순서대로 4지선다 퀴즈를 순차 진행합니다. 완료 후 점수 확인 및 최고 점수 갱신 시 자동 저장됩니다. |
| **2** | **랜덤 퀴즈 풀기 (무작위 순서)** | 등록된 문제의 순서를 무작위(`random.shuffle`)로 섞어 출제합니다. |
| **3** | **퀴즈 추가 (객관식 4문항)** | 문제 내용, 4개의 선택지, 1~4번 정답 번호를 입력받아 신규 퀴즈를 추가하고 `state.json`에 즉시 저장합니다. |
| **4** | **퀴즈 삭제** | 현재 등록된 문제 목록을 확인하고, 삭제할 번호를 선택하여 특정 퀴즈를 제거 후 `state.json`에 즉시 반영합니다. |
| **5** | **퀴즈 목록 보기** | 등록된 전체 퀴즈의 문항 내용, 4개의 보기, 정답(★ 표기)을 한눈에 조회합니다. |
| **6** | **점수 확인** | 역대 최고 점수(`🏆 high_score`)와 최근 풀이한 퀴즈의 점수 및 정답률(`📝 last_score`)을 확인합니다. |
| **7** | **종료** | 현재 데이터 상태를 최종 점검/저장하고 안전하게 프로그램을 종료합니다. |

### 💡 데이터 영속화 (Data Persistence)
- 프로그램을 종료했다가 다시 실행하더라도 사용자가 추가한 퀴즈와 달성한 역대 최고 점수가 그대로 유지됩니다.
- 문제 추가, 삭제, 풀이 완료 시점마다 자동으로 파일에 반영되므로 예기치 않은 종료에도 데이터가 손실되지 않습니다.

## 6. 데이터 파일 설명 (state.json)

프로젝트 루트의 `state.json`은 프로그램의 상태 데이터를 보관하는 파일입니다.

- **파일 위치**: 프로젝트 루트 (`state.json`)
- **문자 인코딩**: `UTF-8` (한글 깨짐 방지 및 `ensure_ascii=False` 적용)
- **포맷**: JSON (JavaScript Object Notation)

### 데이터 스키마 및 구조

```json
{
  "high_score": 0,
  "quizzes": [
    {
      "question": "파이썬에서 콘솔 화면에 데이터를 출력할 때 사용하는 기본 내장 함수는?",
      "options": [
        "input()",
        "print()",
        "len()",
        "type()"
      ],
      "answer": 2
    },
    {
      "question": "파이썬의 시퀀스 자료형 중 요소를 변경할 수 없는(immutable) 불변 자료형은?",
      "options": [
        "list",
        "dict",
        "tuple",
        "set"
      ],
      "answer": 3
    }
  ]
}
```

### 필드 상세 설명

| 필드명 | 타입 | 설명 |
|:---|:---:|:---|
| `high_score` | `Integer` | 사용자가 퀴즈 풀기에서 달성한 **역대 최고 점수**(맞힌 문제 수)입니다. 새 기록 달성 시 자동으로 갱신됩니다. |
| `quizzes` | `Array` | 현재 등록되어 있는 객관식 퀴즈 객체 목록입니다. |
| `quizzes[].question` | `String` | 퀴즈의 문제 지문 내용입니다. |
| `quizzes[].options` | `Array[String]` | 1번부터 4번까지 제공되는 4개의 선택지 리스트입니다. |
| `quizzes[].answer` | `Integer` | 올바른 정답 선택지 번호 (1 ~ 4)입니다. |

### 안전성 및 예외 처리
- `state.json` 파일이 존재하지 않는 경우: 프로그램 시작 시 기본 파이썬 퀴즈 5문항 및 `high_score: 0`으로 자동 초기화하고 신규 `state.json` 파일을 생성합니다.
- 파일 내용이 손상되었거나 유효하지 않은 JSON 형식인 경우: 예외를 감지(`try-except`)하여 프로그램을 비정상 종료하지 않고 기본 데이터로 안전하게 복구합니다.
